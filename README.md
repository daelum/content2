# Walk Film Kit

Phone-friendly content hub for Daelum Marx: opening hooks, film-ready 10–20s scripts, walk-film cue sheet, Instagram transcripts, and a short how-to (hook → script → Osmo walk).

**Live (Cloudflare):** https://walk-film-kit.pages.dev/

## Open locally

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/` in Safari.

## Rebuild content

If Project store docs change, point `build_data.py` at those markdown sources and run:

```bash
python3 build_data.py
```
